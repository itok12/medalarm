# MedAlarm Privacy Policy

Updated March 29, 2026

MedAlarm stores the account information, medicine schedules, reminder preferences, and adherence history needed to provide the product experience.

## Data We Store

- Username and email address
- Password hash
- Timezone, default alarm time, and email reminder preference
- Medicines, alarms, adherence logs, and caregiver links created by the user
- Optional telemetry events and crash reports when deployment-level analytics integrations are enabled

## Data Sharing

- MedAlarm does not sell personal data.
- Caregivers can only see adherence history for patients they have been explicitly linked to.
- MedAlarm does not allow caregivers to edit medicines or alarms in this version.

## Questions

Use the support and contact routes in the app or the repository links for help.
